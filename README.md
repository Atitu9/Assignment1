### Part 3. Introduction to CSS
### Step 9 - Introduction to CSS
I added CSS styling to the webpage to customize background colors, text colors, fonts and spacing.
### Step 10 - Inline CSS
I used inline CSS (`style="color: #0056b3;"`) to change the text color of the "About me" paragraph.
### Step 11 - Internal CSS
I practiced defining style rules inside the HTML document structure.
### Step 12 - External CSS
I created an external `style.css` file and linked it to my HTML file using `<link rel="stylesheet" href="style.css">`.
### Step 13 - CSS Selectors
I used element selectors (`p`, `h2`), class selectors (`.highlight`) and ID selectors (`#main-heading`) in my CSS file.
### Step 14 - Classes and IDs
I created the `.highlight` class for highlighting multiple elements (e.g., hobbies and mood text) and the `#main-heading` ID for my main header.
